## v26.1.6 · 普通用户版

- **首次使用配置引导**：遇到已识别的缺依赖或配置异常，说明应在本机、容器还是远程设备处理。涉及 AI Python 或外部工具时可直接打开相应设置；原始日志保留，平台不会自动安装或重跑。
- **Linux 中文输入**：Linux x86_64 包内附与 Qt 版本匹配的 Fcitx4／搜狗输入插件，不修改系统输入法。Fcitx5 仍需匹配的原生插件。
- **模型工具**：本地 PT／ONNX 视频和图片目录推理、模型类别读取、远程 STAR 自动标注、TensorRT 构建队列与远端任务恢复。
- **数据处理**：抽帧输出目录策略、按工位区域和完整工序去重、裁剪复制／安全替换、运行耗时和可区分的历史记录。

下载对应 Windows x86_64、Linux x86_64、macOS Intel 或 macOS Apple Silicon 的压缩包，**完整解压到新目录**再启动。旧版本不要在运行任务时替换。普通用户版依旧需要有效授权码，不包含管理或签发工具。

标准包无需 Conda 即可启动，但不内置 PyTorch／Ultralytics、第三方 STAR 打包工具、Docker 量化环境或远程设备驱动。Windows 可使用包内 `AI-Environment-Setup` 或单独下载环境安装脚本；已有环境可直接在「本机设置 → 本地 AI 运行时」选择对应的 Python。
