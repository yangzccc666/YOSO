# YOLO数据处理平台 v26.1.3

## 更新内容

- 视频抽帧支持输入多个文件夹路径，递归查找视频，自动去重并根据资源并行处理。
- 项目或场景标识留空时，抽帧文件夹和图片名称采用原视频名称，并保留抽帧方式等信息。
- 视频裁剪支持自定义输出名称，重名自动追加后缀，不覆盖已有文件。
- 远程实时 AI 推理增加 STAR 模型历史库，可搜索并恢复模型路径、类别名称及置信度配置。
- 推理预览支持空格播放/暂停，逗号后退一帧、句号前进一帧；输入框编辑和中文输入法不受快捷键影响。
- 上一帧、下一帧按钮支持长按连续逐帧，串行等待画面返回，松开、移出或失焦时停止，避免请求积压。
- 改进逐帧定位与预览状态同步，避免旧画面覆盖新画面。

## 安装与使用

提供 Windows x86_64、Linux x86_64、macOS Intel 和 macOS Apple Silicon 四种安装归档。解压后运行对应程序即可，不要求先安装 conda；模型训练及推理所需的 AI 环境按实际功能单独配置。

本发行版为普通用户版，首次使用需要有效授权码，不含管理员授权码生成工具、私钥或本机连接密码。旧版本继续保留，便于回退。

Windows/macOS 程序尚未进行发行者签名或 Apple 公证，可能触发系统安全提示。请确认文件来自本项目 GitHub Release 后再允许运行。
