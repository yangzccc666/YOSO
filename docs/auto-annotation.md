# 模型自动标注

在“数据集处理 → 模型自动标注”中选择本机图片文件夹、训练后的 Ultralytics 目标检测 PT 模型，然后点击一键运行。默认自动使用本机 yolo26 环境，也可以填写 Python 解释器路径。

- 每张图片旁生成同名 VOC XML，框使用原图像素坐标，类别名称来自模型。图片不修改。
- 默认置信度 0.5、IoU 0.7、推理尺寸 640；支持设备、类别编号筛选和递归扫描子目录。
- 已有 XML 默认跳过。“备份后覆盖”会先复制旧 XML 到图片根目录 `.annotation_backups/<任务编号>/`，保持相对路径。需要恢复时将备份 XML 复制回对应图片目录。
- 无目标时默认生成不含 object 的 XML；请人工复核，未检出不代表一定没有目标。
- 同一目录存在 `a.jpg` 与 `a.png` 等同名图片时会在写入前报错，避免共用 `a.xml`。
- 终止任务会停止推理子进程，已生成的 XML 保留。逐张输出进度，失败图片记录在日志中。

当前支持 Ultralytics 检测模型（包括 YOLO26），不支持旧 YOLOv5 仓库格式、分割、旋转框和分类模型。自动标注结果需要在标注工具中人工复核后再用于训练。
