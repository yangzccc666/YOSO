## v26.1.8 · 普通用户版

- **倒计时提醒**。可添加多个带备注的倒计时。到时显示醒目的桌面弹窗并播放提示音，提醒保留到手动确认。
- **Windows 视频抽帧**。修复中文路径下的视频读取与图片保存问题，读取、解码或写入失败时提供对应错误信息。
- **远程 YOLO 数据集划分**。Windows 客户端会保留服务器上的 Linux 路径格式，避免把正斜杠改成反斜杠后导致远程目录无法找到。

下载适合 Windows x86_64、Linux x86_64、macOS Intel 或 macOS Apple Silicon 的压缩包，完整解压后启动。已有普通用户授权可继续使用。
