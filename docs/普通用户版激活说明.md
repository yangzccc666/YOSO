# 普通用户版激活说明

GitHub 源码和 Release 仅提供普通用户版，包含数据处理功能与离线密钥验证，不包含授权码生成、签发维护工具或签发私钥。

## 首次使用

1. 下载与你的系统对应的 Release 安装包并解压。
2. 打开 YOLO 数据处理平台，将提供者发给你的完整授权码粘贴到激活界面。
3. 验证通过后进入平台，下次启动自动读取本机激活状态。

没有有效授权码时不能访问数据处理功能。授权码被修改、过期或命中已更新的撤销名单时，会显示对应原因。需要授权码或续期时，请联系程序提供者。

## 有效期与更新

授权支持长期有效或指定有效期。授权默认不绑定电脑，在另一台电脑首次运行时需要重新输入。有效期以本机 UTC 时间验证。

更新程序时保留原平台数据目录，即可继续使用已保存的激活记录。密钥到期后，平台会重新显示激活界面，输入新的有效密钥即可继续使用。

激活记录保存在平台数据目录的 `activation.json` 中。Windows 使用用户 LocalAppData 下的 `YOLODataPlatform`，macOS 使用用户 `Library/Application Support/YOLODataPlatform`，Linux 使用用户 `.local/share/yolo-data-platform`；源码运行默认使用项目内的 `runtime` 目录。

普通用户版不会因输入不同类型的授权码而出现授权管理入口或签发接口。更新离线撤销名单需要更新程序，不依赖授权服务器。

## 本机依赖

桌面发行包已包含平台运行组件。Conda 不是启动平台的必需条件；本地 PT 推理、训练、模型导出或 Docker 等处理功能的依赖，按各功能提示单独配置。
