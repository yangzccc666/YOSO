# 差异优先的图片去重

推荐在“图片智能去重”选择“差异优先去重（自动）”，先点“先分析，不移动图片”。不用设置相似度阈值、最低保留比例或删除张数。

目标是移除大量近重复背景/动作画面并保留实际变化，不是保留固定百分比或删除固定数量。比如六轮操作中每轮重复出现同样的四个画面，允许保留四个代表样本；偶发动作、局部明显变化、光照变化及标注差异应保留。若必须完整保留第一轮，请改用“完整工序循环去重”，指定参考轮起止图片。

## 判定流程

1. 读取原始图片，按尺寸/位深、全部同名标注分组。无法读取、符号链接、共享同名标签等歧义输入不会直接移除。
2. 完整像素摘要优先找到精确重复；再用轻量边缘/颜色索引检索已经保留的代表样本。可以跨同目录内非相邻图片、跨视频前缀匹配；不同目录不互相比较。
3. 缩略特征只提名，真正的移除决定在原始分辨率上复核。允许有限传感器/压缩噪声，检查整体差异、局部块变化、明显局部连通变化以及标注类别、数量、位置。
4. 只有复核通过才移出，引用的对照图必须仍被保留。被移除图片不会再作为别的图片的参考，避免 A≈B、B≈C 却把与 A 不同的 C 也一路删掉。

自动模式有内部固定的视觉规则与有界的噪声估计，不要求用户设置数值；这不意味着算法没有判据，更不意味着能证明工艺语义相同。微弱缺陷、噪声与小动作的边界需要真实数据校验。全局索引和候选数量有工作内存/计算上限，可能漏掉部分重复，但不会因数据多就放松复核标准。

## 查看与回滚

- 分析只在原目录外写 `analysis.json`，不移动图片/标注。报告包含每张拟移除图片、仍保留的对照文件名、原因、精确/近重复类型与差异指标。
- 执行将图片和同名 TXT/XML/JSON 移入图片目录外的批次备份，不永久删除；`manifest.json` 保留对应关系。选择“回滚最近一次”恢复，目标位置有同名文件时停止，避免覆盖。
- 分析期间检测到图片或标注变化则整批不执行；移动过程中取消或失败会尝试撤回已移动文件。
- 新默认模式为自动模式；已经显式保存的旧模式不会被覆盖，切换并保存默认值即可。旧配置中的保留比例/连续移除配额被忽略，所有模式都不靠数量目标决定移除。

## 其他模式

“仅精确重复”只处理完整像素一致，不合并压缩/噪声差异。“连续相似帧去重”保留旧相邻序列提名逻辑和首尾锚点，但取消数量配额，并增加原图复核。“完整工序循环去重”继续保护参考轮、对齐变速轮次，逐张通过原图复核才移除整轮。

自动去重不等于评估所有样本对 YOLO 的训练贡献。重要或稀有缺陷请先人工抽查；不确定时用“仅精确重复”，或回滚后调整数据范围。

## 工位工序去重：忽略旁边工位的变化

原“差异优先去重（自动）”仍是严格的全图近重复判断：全图任意位置出现人员/设备变化、或标注框位置变化，都会倾向保留。因此它不适合“目标工位动作重复、其他工位一直在动”的素材。新模式 **工位工序去重（忽略背景）** 是用户明确关注范围后的任务导向视觉去重，不是把全图像素阈值简单调低。

操作步骤：

1. 填入真实图片文件夹。多个工位在子目录中时开启“包含子文件夹”，无需复制图片或事先交给 AI。
2. 选择“工位工序去重（忽略背景）”，点击“读取真实图片目录”。该步骤只读取示例图片，不运行去重、不修改图片。
3. 从下拉菜单选择每个实际图片目录，在示例图上拖动框选完整作业区，点击“保存本工位区域”。可输入该目录中的其他图片文件名更换示例。手、工具、工件及其运动范围都应包含，尽量排除其他工位。没有配置的目录会在批量开始前拦截，避免错误套用区域。
4. 默认为“平衡（推荐）”，无需填写数值阈值。先分析，看拟移除数量和报告中的对照样本；确实重复仍偏保守时，可改“较强”再次分析。不要直接从最强开始处理重要样本。
5. 确认后执行去重，重复图和同名标注移入可回滚备份。区域、模式和力度可“保存为默认值”复用。

判定说明：

- 只在已保存的相对矩形区域内提取结构、颜色及局部块特征，区域外像素不参与。背景无论怎么变化，都不会影响该区域的比较。区域内的旁人遮挡/无关动作仍可能影响，不能自动分离相互重叠的工位。
- 在目录内跨非相邻图片查找仍保留的动作代表图；允许有限手部位置/压缩噪声与亮度抖动，不要求整张图或 ROI 像素一致。轮次不用固定几秒，同一动作可以在不同轮次出现。
- **不自动识别完整工序起止，也不承诺完整保留第一轮每张图片**：这是动作画面代表样本选择，不是训练了工序识别模型。若必须原样保留第一轮所有帧，继续使用“完整工序循环去重”（当前仍按严格全图规则核验）。
- 区域内检测框的类别、数量不同或框位置显著变化时保护；同类别、同数量且框 IoU 至少 0.6 时允许有限标注抖动。区域外的标注变化明确忽略。支持 YOLO 检测 TXT、VOC 矩形 XML、LabelMe 矩形 JSON；不支持的分割/旋转/未知标注或坏标注原样保留。
- 整体相近仍需局部结构与局部颜色复核；明显变化倾向保留。但这是降噪、缩放后的视觉规则，**可能合并小缺陷、细微工艺差异或语义不同但画面接近的样本**。重要缺陷应有明确类别标注并先抽查；零误删需求用严格/精确模式。
- 不设删除目标或保留比例，不以“数据多就多删”为规则。参考图只来自仍保留的样本，避免在逐渐变化的图片之间链式删除。
- 分析与执行报告记录实际区域、力度、规则版本、结构/局部/颜色差异分数、保留的对照文件名，以及标注拦截等统计。若没有移除，会提示检查区域是否仍含其他工位；不会假装完成了删除。

不同目录的区域独立保存并绑定根目录，改变输入路径需重新读取。只有构图一致时才使用“填充未配置工位（相同视角）”，该操作要求确认且不覆盖已配置工位。一个目录内混有不同机位或相机移动的图片，应先分目录再处理。

## 多工位目录批量处理

输入场景上层目录，开启“包含子文件夹（各目录独立去重）”，再点“先分析，不移动图片”。任意深度中直接包含 JPG/JPEG/PNG/BMP/WEBP 的目录都会成为一个独立处理单元；上层目录本身有图片也单独处理。比如 `场景/工位A/images` 与 `场景/工位B/images` 各自保留代表图片，不会把不同工位的样本相互删除。空目录、备份目录、符号链接目录/图片不会成为处理单元。

- 同一套设置按目录串行处理，限制工作内存；输出显示目录序号、进度、每目录保留/移出数量和总计。某目录失败会明确提示并继续其余目录，不把失败目录算作成功。
- 每目录的分析报告、图片/同名标注备份延续原有格式；上层目录的同级隐藏备份中额外保存 `batch.json`，列出所有目录结果及对应清单路径。运行历史可查看这些报告。
- 批量回滚：保持上层目录路径和“包含子文件夹”开启，选择“回滚最近一次”。仅恢复该上层目录最近一次有移出文件的批量任务，不会连带恢复更早的独立单目录去重。全部目录先检查同名冲突，任何冲突都会停止回滚，避免覆盖新文件。较新的纯分析/无移除任务不影响查找最近可回滚批次。
- 中途停止：当前目录未完成的文件移动撤回；此前成功完成目录的结果保留并纳入批次，可一并回滚。回滚中取消则撤回本次已恢复的文件，保留原备份状态。
- 默认关闭子目录扫描以兼容原有操作，可开启并“保存为默认值”下次复用。“完整工序循环去重”需逐目录指定各自参考轮，不支持用同一组参考图片批量处理不同工位。
